# Wemos_D1_mini_WiFi_manager_setup_in_Cpp

Неблокуючий менеджер Wi-Fi з **Captive Portal** (`WiFiSetup`) та локальним вебсервером керування реле (`ESP8266WebServer`) на базі **Wemos D1 mini (ESP8266)**, написаний на **C++**.

Проєкт реалізує динамічне налаштування Wi-Fi без жорсткого «зашивання» облікових даних у код, автоматичне перепідключення та керування навантаженням через веб-інтерфейс у локальній мережі.

---

## Основні можливості

* **Неблокуюча архітектура (`millis()` + кінцевий автомат):** У коді відсутні блокуючі `delay()`, використовується кінцевий автомат (`CONNECTING`, `SUCCESS`, `FAILED`) та `yield()`, що запобігає зависанню й перезавантаженню через сторожовий таймер (`WDT`).
* **Captive Portal / Config Portal (`WiFiSetup`):** Можливість запустити точку доступу (`192.168.4.1`) автоматично після таймауту підключення або на вимогу для введення SSID та пароля Wi-Fi.
* **Керування через Serial Monitor:** Швидкі команди для діагностики та керування станом мережі й порталу без перепрошивки.
* **Локальний вебсервер керування реле:** Веб-інтерфейс на порту `80` з відображенням стану (`ON` / `OFF`) та перемиканням каналу реле (з підтримкою активного низького рівня `LOW`).

---

## Апаратне забезпечення

* **Мікроконтролер:** Wemos D1 mini (ESP8266)
* **Виконавчий пристрій:** Модуль реле (зокрема одноканальний модуль на базі `SRD-05VDC-SL-C` з керуванням активним низьким рівнем `LOW`)
* **Живлення:** `5V` / `VIN` та спільна маса `GND`

---

## Схема підключення (1 канал реле)

| Сигнал / Вивід | Пін Wemos D1 mini | GPIO | Примітки |
| :--- | :---: | :---: | :--- |
| **Керування реле (`IN`)** | `D2` | `GPIO 4` | Активний низький рівень (`LOW` — увімкнено, `HIGH` — вимкнено) |
| **Живлення реле (`VCC`)** | `5V` / `VIN` | — | Стабілізоване живлення котушки реле |
| **Земля (`GND`)** | `GND` | — | Спільний `GND` для Wemos D1 mini та модуля реле |

---

## Команди Serial Monitor (`115200` бод)

* `p` — увімкнути або вимкнути Config Portal (`http://192.168.4.1`)
* `r` — очистити збережені налаштування Wi-Fi (`resetSettings()`)
* `s` — вивести поточний статус (підключення, активність порталу, збережений SSID, IP-адреса, RSSI)
* `h` — вивести довідку по командах

---

## Запуск та використання

1. Відкрийте проєкт у середовищі розробки з підтримкою C++ для ESP8266 (наприклад, **PlatformIO** у VS Code).
2. Підключіть **Wemos D1 mini** до комп'ютера через USB.
3. Зберіть та завантажте прошивку на плату.
4. Відкрийте **Serial Monitor** на швидкості `115200` бод, щоб побачити статус підключення або запуску порталу.
5. Якщо пристрій підключено до вашої Wi-Fi мережі — відкрийте його локальну IP-адресу (наприклад, `http://192.168.0.114`) у браузері для керування реле. Якщо мережу не налаштовано — підключіться до точки доступу порталу та перейдіть на `http://192.168.4.1`.
